=== DAY 29 LEARNING NOTES ===

- Today's Focus: Shifting from "How to Code" to "How to Detect".
- Key Insight: An IP address (IOC) is a weak signal because attackers change it daily. 
  But "Behavior" (TTP - Tactics, Techniques, and Procedures) is a strong signal.
- MITRE ATT&CK: Learned how to use MITRE IDs to categorize hacker activities. 
  It’s like a universal language for security teams.
- Difficulty: Thinking like an attacker was challenging but helped me understand 
  why we need behavioral detection rules instead of just static lists.
